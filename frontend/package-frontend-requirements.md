# Frontend Dependencies

## Framework

- `vue`: Vue 3 application framework.
- `vue-router`: Client-side routing.
- `pinia`: Application state management.

## UI And Visualization

- `element-plus`: UI component library.
- `@element-plus/icons-vue`: Element Plus icon components.
- `echarts`: Charting library.
- `vue-echarts`: Vue wrapper for ECharts.
- `three`: 3D rendering for the robot-arm visualization.

## Communication

- `axios`: HTTP client.
- `socket.io-client`: WebSocket client.
- `mqtt`: MQTT client package.

## Tooling

- `vite`: Build tool and dev server.
- `@vitejs/plugin-vue`: Vue support for Vite.
- `sass`: CSS preprocessor.
- `@types/node`, `@types/three`: TypeScript type definitions.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```
